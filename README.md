# タバタタイマー

iPhone のホーム画面に追加して使う、シンプルなインターバルタイマー（GitHub Pages で公開）。

## 設定項目
| 項目 | 内容 |
|---|---|
| 準備時間 | スタート前のカウントダウン（0秒で省略） |
| 運動時間 | 1ラウンドの運動時間 |
| 休憩時間 | ラウンド間の休憩 |
| ラウンド数 | 「運動→休憩」を何回繰り返すと1セットか |
| セット数 | セットを何回行うか |
| セット間休憩 | セットとセットの間の休憩 |

設定は端末に保存され、次回も同じ値で開きます。

## 音
- 切り替わり3秒前から「ピッ・ピッ・ピッ」
- 運動開始：高い「ピー」／休憩開始：低い「ピー」／セット間休憩：「ピッ・ピー」／完了：3連音
- 音楽アプリを止めずに上から重ねて鳴らします（iOS の消音スイッチが ON だと鳴りません）

## 注意
- タイマー動作中は画面が自動で消えないようにしています。画面をロックしたりアプリを切り替えると音は鳴りません。
